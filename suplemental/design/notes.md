We are making a worship leader app. In the first version of the app we want to include the following features:

- Adding/Editing songs.
  - Song name
  - Lyrics 
  - Chords (that are precisely positioned in the lyrics)
  - Lyrics Author
  - Melody author (or whatever the term is)
  - YouTube link
- Deleting songs
  - Give a warning before deletion
- Search songs
  - There is a live update to the list being displayed as user types the name or word in lyrics or author
- Display songs with chords
  - There should be an option to hide the chords
  - Chords (when shown) are above the lyrics in the correct position
- Each song has it's own YouTube link on the app bar
- There should be an option for users to have set list
  -  This is a collection of songs
  - People should be able to share a set with others
  - There are live sets and copy sets
    -  A live set means that people can see the edits happening live
    - A copy set means that you can share a current set with someone else but it isn't live
- Songs should be favoriteable
- There is a bottom menu bar that five buttons:
  1. Search
  2. Favorites (These are also shareable)
  3. Add song
  4. Tuner
  5. Profile (includes settings)
- App should support English and Mongolian
